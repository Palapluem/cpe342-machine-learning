\section*{1. ภาพรวมของปัญหาและวัตถุประสงค์\\ \large(Problem Overview \& Objectives)}

ในงานมอบหมาย Assignment 4 นี้ เราศึกษา พัฒนา และเปรียบเทียบประสิทธิภาพของแบบจำลองประเภท \textbf{Tree-Based และ Ensemble Learning} เพื่อทำนายผลการพิจารณารับนักศึกษาเข้าศึกษาต่อในหลักสูตรบริหารธุรกิจมหาบัณฑิต (\textbf{MBA Admission Prediction}) บนชุดข้อมูล \texttt{MBA.csv} ซึ่งประกอบด้วยข้อมูลประวัติของผู้สมัครรวม $N = 6,194$ รายการ โดยมีกลุ่มข้อมูลที่ได้รับการตัดสินผลแล้ว (Labeled Cohort) จำนวน $1,000$ รายการ แบ่งเป็นผู้ที่ผ่านการคัดเลือก (\textbf{Admit: 900 ราย หรือ 90\%}) และผู้ที่อยู่ในบัญชีสำรอง (\textbf{Waitlist: 100 ราย หรือ 10\%})

\subsection*{วัตถุประสงค์หลักของการทดลอง}
\begin{enumerate}[leftmargin=18pt, itemsep=2pt]
    \item เพื่อศึกษาและสร้างแบบจำลองการจำแนกประเภท 3 สถาปัตยกรรมหลักตามเนื้อหา Lecture 5:
    \begin{itemize}
        \item \textbf{Decision Tree Classifier}: ต้นไม้ตัดสินใจเดี่ยวแบบแบ่งส่วนตามเกณฑ์ Entropy และ Information Gain
        \item \textbf{Random Forest Classifier}: โมเดลกลุ่มแบบ Bagging ร่วมกับการสุ่มเลือกคุณลักษณะ (Random Subspace)
        \item \textbf{Gradient Boosting Classifier}: โมเดลกลุ่มแบบ Boosting แบบเรียงลำดับที่ปรับจูนค่าน้ำหนักตาม Pseudo-Residuals
    \end{itemize}
    \item เพื่อวิเคราะห์และจัดการกับภาวะ \textbf{ข้อมูลไม่สมดุล (Class Imbalance)} ในสัดส่วน 9:1 ผ่านการปรับค่าน้ำหนักความสูญเสียแบบถ่วงดุล (\texttt{class\_weight='balanced'}) และการใช้เกณฑ์ประเมินผลที่เหมาะสม
    \item เพื่อวิเคราะห์ความสำคัญของตัวแปรคุณลักษณะ (\textbf{Feature Importance}) ได้แก่ เกรดเฉลี่ยสะสม (GPA), คะแนนสอบ GMAT, ประสบการณ์การทำงาน (Work Experience) และสายงานธุรกิจ (Industry) ต่อผลการคัดเลือก
    \item เพื่อประเมินประสิทธิภาพเชิงลึกด้วยตัวชี้วัดที่หลากหลาย ได้แก่ Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC Curve และ 5-Fold Stratified Cross-Validation
\end{enumerate}

\section*{2. กรอบทฤษฎีและคณิตศาสตร์\\ \large(Theoretical Framework \& Mathematical Formulations)}

เนื้อหาในส่วนนี้อิงตามเอกสารการสอน \textbf{Lecture 5: Tree-Based and Ensemble Models}

\subsection*{2.1 การเหนี่ยวนำต้นไม้ตัดสินใจและเกณฑ์การแบ่ง\\ \normalsize(Decision Tree Induction \& Splitting Criteria)}
ต้นไม้ตัดสินใจ (Decision Tree) ใช้ระเบียบวิธีแบ่งแยกแบบวนซ้ำ (Recursive Partitioning) โดยมีเป้าหมายเพื่อแบ่งกลุ่มข้อมูลในแต่ละ Node ให้มีความบริสุทธิ์ (Purity) สูงที่สุด

\subsubsection*{1. เอนโทรปี (Entropy)}
เอนโทรปีคือค่าชี้วัดความไร้ระเบียบหรือความไม่แน่นอนของชุดข้อมูล $S$ นิยามโดย:
\begin{equation}
    H(S) = -\sum_{i=1}^{C} p_i \log_2(p_i)
\end{equation}
สำหรับปัญหา Binary Classification ($C = 2$): $H(S) = -p_1 \log_2(p_1) - p_2 \log_2(p_2)$ โดยหากทุกตัวอย่างอยู่ในคลาสเดียวกันหมด $H(S) = 0$ (Pure) และหากมีสัดส่วนคลาสละ 50\% $H(S) = 1.0$ (Maximum Disorder)

\subsubsection*{2. อัตราการได้รับสารสนเทศ (Information Gain: IG)}
อัตราการลดลงของเอนโทรปีเมื่อทำการแบ่งชุดข้อมูล $S$ ด้วยตัวแปรคุณลักษณะ $A$:
\begin{equation}
    IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)
\end{equation}
อัลกอริทึมจะเลือกตัวแปร $A^*$ และจุดตัด (Split Point) ที่ให้ค่า $IG(S, A)$ สูงที่สุดในแต่ละ Node

\subsubsection*{3. ดัชนีความไม่บริสุทธิ์ของจีนี (Gini Impurity)}
เกณฑ์ทางเลือกที่นิยมใช้ในสถาปัตยกรรม CART:
\begin{equation}
    Gini(S) = 1 - \sum_{i=1}^{C} p_i^2
\end{equation}

\subsection*{2.2 การตัดแต่งกิ่งต้นไม้และการควบคุมความซับซ้อน\\ \normalsize(Tree Pruning \& Regularization)}
ต้นไม้ตัดสินใจเดี่ยวที่ไม่มีการควบคุมความลึกจะขยายกิ่งก้านจนกระทั่งทุก Leaf Node มีเอนโทรปีเป็นศูนย์ ซึ่งก่อให้เกิดภาวะ \textbf{Overfitting} (High Variance) การควบคุมทำได้โดยกำหนดความลึกสูงสุด (\texttt{max\_depth}), จำนวนตัวอย่างขั้นต่ำในการแบ่ง (\texttt{min\_samples\_split}) และการตัดแต่งกิ่งตามความซับซ้อนของต้นไม้ (Cost-Complexity Pruning: CCP):
\begin{equation}
    R_\alpha(T) = R(T) + \alpha |T|
\end{equation}
เมื่อ $R(T)$ คือความคลาดเคลื่อนในการจำแนก, $|T|$ คือจำนวน Terminal Nodes และ $\alpha \ge 0$ คือค่าปรับโทษความซับซ้อน

\subsection*{2.3 อัลกอริทึม Random Forest และการลดความแปรปรวน\\ \normalsize(Random Forest \& Variance Reduction via Bagging)}
Random Forest แก้ไขข้อจำกัดด้านความแปรปรวนสูงของต้นไม้เดี่ยวด้วยการผสาน 2 กลไก:
\begin{enumerate}[leftmargin=18pt, itemsep=2pt]
    \item \textbf{Bootstrap Aggregating (Bagging)}: สุ่มสร้างชุดข้อมูลฝึกสอนย่อย $B$ ชุด โดยการสุ่มแบบใส่คืน (Sampling with Replacement) ขนาด $N$ เท่าเดิม
    \item \textbf{Random Subspace (Feature Sampling)}: ในการแบ่งแต่ละ Node จะสุ่มเลือกคุณลักษณะมาพิจารณาเพียง $m = \lfloor\sqrt{p}\rfloor$ จากทั้งหมด $p$ คุณลักษณะ เพื่อลดความสัมพันธ์ร่วมกันระหว่างต้นไม้แต่ละต้น (Tree Decorrelation)
\end{enumerate}

ทฤษฎีการลดความแปรปรวนของโมเดลกลุ่มระบุว่า หากต้นไม้ $B$ ต้นมีความแปรปรวน $\sigma^2$ และมีค่าสหสัมพันธ์เฉลี่ย $\rho$ ความแปรปรวนของค่าเฉลี่ยของโมเดลกลุ่มจะเป็น:
\begin{equation}
    \text{Var}\left(\frac{1}{B}\sum_{b=1}^B T_b(x)\right) = \rho \sigma^2 + \frac{1 - \rho}{B}\sigma^2
\end{equation}
เมื่อ $B \to \infty$ พจน์ที่สองจะเข้าใกล้ศูนย์ ทำให้ความแปรปรวนรวมลดลงเหลือเพียง $\rho \sigma^2$ ซึ่งการสุ่มเลือก Feature จะช่วยลดค่า $\rho$ ให้ต่ำลงอย่างมีนัยสำคัญ

\subsection*{2.4 การเรียนรู้แบบ Gradient Boosting\\ \normalsize(Gradient Boosting via Sequential Residual Fitting)}
Gradient Boosting สร้างแบบจำลองกลุ่มแบบเพิ่มพูน (Additive Model) ทีละขั้นตอน:
\begin{equation}
    F_M(x) = F_0(x) + \sum_{m=1}^M \eta \cdot h_m(x)
\end{equation}
เมื่อ $\eta \in (0, 1]$ คืออัตราการเรียนรู้ (Learning Rate / Shrinkage) และ $h_m(x)$ คือ Base Learner (ต้นไม้ขนาดเล็ก) ที่ถูกเทรนให้เข้ากับค่า \textbf{Pseudo-Residuals} ซึ่งคือความชันลบของ Loss Function $L(y, F(x))$:
\begin{equation}
    r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F = F_{m-1}}
\end{equation}
สำหรับ Binary Log-Loss ค่า $r_{im} = y_i - p_{m-1}(x_i)$ โดย $p(x) = \frac{1}{1 + e^{-F(x)}}$

\subsection*{2.5 เมทริกซ์และตัวชี้วัดประสิทธิภาพสำหรับข้อมูลที่ไม่สมดุล\\ \normalsize(Evaluation Metrics for Imbalanced Datasets)}
เนื่องจากชุดข้อมูลมีคลาส Admit มากถึง 90\% การใช้ Accuracy เพียงอย่างเดียวจะเกิด \textbf{Accuracy Paradox} จึงจำเป็นต้องประเมินด้วยเมทริกซ์เฉพาะทาง:
\begin{equation}
    \text{Precision} = \frac{TP}{TP + FP}, \quad \text{Recall (Sensitivity)} = \frac{TP}{TP + FN}
\end{equation}
\begin{equation}
    F_1\text{-Score} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
\end{equation}
\begin{equation}
    \text{ROC-AUC} = \int_0^1 \text{TPR}(\text{FPR}^{-1}(u))\,du
\end{equation}

\section*{3. โครงสร้างชุดข้อมูลและการจัดเตรียมตัวแปร\\ \large(Dataset Architecture \& Preprocessing)}

ชุดข้อมูล \texttt{MBA.csv} มีขนาด $6,194$ แถว และ $10$ คอลัมน์ โดยมีรายละเอียดการเตรียมข้อมูลดังนี้:
\begin{itemize}[leftmargin=18pt, itemsep=2pt]
    \item \textbf{การคัดกรองข้อมูลเป้าหมาย}: คัดเลือกเฉพาะ $1,000$ แถวที่มีการบันทึกสถานะ \texttt{admission} (`Admit' = 900 ราย, `Waitlist' = 100 ราย)
    \item \textbf{การกำหนดคลาสเป้าหมาย}: กำหนดให้ $y = 0$ สำหรับกลุ่ม `Admit' (เสียงข้างมาก) และ $y = 1$ สำหรับกลุ่ม `Waitlist' (เสียงข้างน้อย / คลาสที่สนใจ)
    \item \textbf{การตัดตัวแปรระบุตัวตน}: ลบคอลัมน์ \texttt{application\_id} เนื่องจากไม่มีคุณค่าทางการทำนาย
    \item \textbf{การจัดการข้อมูลสูญหาย}: ตัวแปร \texttt{race} มีค่าสูญหาย จึงถูกแทนที่ด้วยกลุ่มระบุเฉพาะ `Missing'
    \item \textbf{การแปลงคุณลักษณะหมวดหมู่}: ตัวแปร \texttt{gender}, \texttt{international}, \texttt{major}, \texttt{race}, \texttt{work\_industry} ถูกแปลงเป็น Category Codes สำหรับสถาปัตยกรรม Tree
    \item \textbf{การแบ่งชุดข้อมูล}: แบ่งข้อมูลแบบ Stratified Train/Test Split ในสัดส่วน 80/20 ($N_{train} = 800$, $N_{test} = 200$) เพื่อรักษาสัดส่วนคลาส $9:1$ ให้คงที่ทั้งสองชุด
\end{itemize}

\section*{5. การอภิปรายผลเชิงลึกและข้อมูลเชิงธุรกิจ\\ \large(In-Depth Discussion \& Business Insights)}

\subsection*{5.1 พลวัตของความไม่สมดุลของข้อมูลและมาตรการแก้ไข\\ \normalsize(Class Imbalance Dynamics \& Cost-Sensitive Mitigation)}
ในชุดข้อมูล MBA นี้ ผู้สมัครที่ได้รับการ Admit มีสัดส่วนถึง 90\% ส่งผลให้แบบจำลองมาตรฐานมีแนวโน้มที่จะทำนายว่าทุกคนได้รับ Admit เพื่อเพิ่มค่า Accuracy ให้สูงที่สุด ($90\%$) การนำเทคนิค \textbf{Cost-Sensitive Weighting} (\texttt{class\_weight='balanced'}) มาปรับใช้ช่วยบังคับให้ Decision Tree และ Random Forest เพิ่มโทษต่อความผิดพลาดในคลาส Waitlist ส่งผลให้สามารถตรวจจับผู้สมัครกลุ่มสำรองได้จริง

\subsection*{5.2 การเปรียบเทียบสถาปัตยกรรมแบบจำลองเดี่ยวและแบบกลุ่ม\\ \normalsize(Single Tree vs. Bagging vs. Boosting Comparison)}
\begin{itemize}[leftmargin=18pt, itemsep=2pt]
    \item \textbf{Decision Tree (White-Box)}: โดดเด่นด้านความโปร่งใส สามารถอธิบายกฎการคัดเลือกให้คณะกรรมการเข้าใจได้ง่าย แต่มีข้อจำกัดด้านความแปรปรวนสูงและความแม่นยำโดยรวมต่ำ
    \item \textbf{Random Forest (Variance Reducer)}: เป็นสถาปัตยกรรมที่ดีที่สุดในภาพรวมสำหรับการจัดลำดับผู้สมัคร (Ranking) โดยให้ค่า Cross-Validation AUC สูงที่สุด ($0.6237$) และมีความทนทานต่อสัญญาณรบกวน
    \item \textbf{Gradient Boosting (Bias Reducer)}: ปรับลดความคลาดเคลื่อนได้อย่างทรงพลัง เหมาะสำหรับการทำนายผลลัพธ์ของคลาสหลัก แต่จำเป็นต้องมีการปรับเกณฑ์ความน่าจะเป็น (Threshold Moving) หากต้องการเพิ่ม Recall ของคลาสสำรอง
\end{itemize}

\subsection*{5.3 ปัจจัยเชิงคุณลักษณะและการแปลผลต่อกระบวนการรับสมัคร\\ \normalsize(Admission Determinants \& Committee Decision Insights)}
ผลการวิเคราะห์ Feature Importance สอดคล้องกับเกณฑ์การรับเข้าศึกษาต่อระดับบัณฑิตศึกษาชั้นนำระดับสากล โดย \textbf{GMAT Score} และ \textbf{GPA} ทำหน้าที่เป็นตัวกรองพื้นฐานทางวิชาการ (Academic Aptitude) ขณะที่ \textbf{Work Experience} และ \textbf{Industry} เป็นตัวตัดสินความพร้อมเชิงวิชาชีพ

\section*{6. ข้อเสนอแนะเชิงกลยุทธ์และการนำไปประยุกต์ใช้\\ \large(Strategic Recommendations)}

\begin{ansbox}
\textbf{ข้อเสนอแนะเชิงกลยุทธ์สำหรับระบบคัดเลือกนักศึกษา (Admissions Pipeline):}
\begin{enumerate}[leftmargin=16pt, itemsep=2pt]
    \item \textbf{ระบบคัดกรองแบบลำดับขั้น (Hybrid Two-Stage Screening Pipeline)}:
    \begin{itemize}
        \item \textit{Stage 1}: ใช้ \textbf{Random Forest} คำนวณค่าความน่าจะเป็นในการคัดเลือกเพื่อแบ่งกลุ่มผู้สมัครที่ผ่านเกณฑ์ชัดเจน (Auto-Admit) ออกจากกลุ่มที่มีความเสี่ยง
        \item \textit{Stage 2}: นำผู้สมัครในกลุ่มก้ำกึ่ง (Borderline / Waitlist Candidates) เข้าสู่การพิจารณาโดยคณะกรรมการ โดยใช้กฎเกณฑ์ของ \textbf{Decision Tree} ช่วยตรวจสอบเงื่อนไขอย่างโปร่งใส
    \end{itemize}
    \item \textbf{การปรับเกณฑ์ Threshold สำหรับกลุ่มสำรอง}: ปรับลดเกณฑ์ความน่าจะเป็น (Classification Threshold) สำหรับกลุ่ม Waitlist จาก 0.50 ลงมาที่ 0.25--0.30 เพื่อเพิ่มความครอบคลุมในการตรวจจับผู้สมัครที่มีศักยภาพแต่อยู่ในกลุ่มสำรอง
\end{enumerate}
\end{ansbox}

\section*{7. สรุปผลการดำเนินงาน\\ \large(Conclusion)}

การทดลองบนชุดข้อมูล \texttt{MBA.csv} ยืนยันถึงคุณลักษณะเด่นและข้อจำกัดของแบบจำลองทั้ง 3 ประเภทตามทฤษฎีใน Lecture 5 โดย \textbf{Random Forest} เป็นแบบจำลองที่มีความเสถียรและให้ประสิทธิภาพในการจำแนกกลุ่มภาพรวมสูงสุด ($\text{CV AUC} = 0.6237$) ขณะที่ \textbf{Decision Tree} มีความโดดเด่นในด้านความสามารถในการอธิบายผล และ \textbf{Gradient Boosting} ให้ค่าความแม่นยำของกลุ่มหลักสูงสุด ($89.50\%$)
