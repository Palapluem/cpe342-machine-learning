\section{Problem Overview}

This assignment investigates the \textbf{iterative approach} to model training using \textbf{Gradient Descent (GD)}. Given a dataset of $n = 100$ observations with variables $X$ and $Y$, the objective is to fit the following \textbf{quadratic model}:

\[
  \hat{y} = C_0 + C_1 x^2
\]

where $C_0$ is the intercept (bias) and $C_1$ is the coefficient for the squared feature $x^2$.

Unlike the closed-form Ordinary Least Squares approach (Assignment 1), gradient descent finds the optimal parameters \textit{iteratively} by repeatedly computing the gradient of the loss function and taking small steps in the direction of steepest descent.

\section{Task 1 — Loss Function}

Given the model $\hat{y}_i = C_0 + C_1 x_i^2$, the \textbf{Mean Squared Error (MSE)} loss function is defined as:

\[
  L(C_0, C_1) = \frac{1}{n} \sum_{i=1}^{n} \left( y_i - \hat{y}_i \right)^2
\]

Substituting the model expression:

\[
  \boxed{L(C_0, C_1) = \frac{1}{n} \sum_{i=1}^{n} \left( y_i - C_0 - C_1 x_i^2 \right)^2}
\]

This is a smooth, convex function in $C_0$ and $C_1$, which guarantees that gradient descent will converge to the global minimum.

% ══════════════════════════════════════════════════════════════════════════════
\section{Task 2 — Gradient of Each Coefficient}

To apply gradient descent, we compute the \textbf{partial derivative} of $L$ with respect to each parameter. Let $e_i = y_i - C_0 - C_1 x_i^2$ denote the residual for observation $i$.

\subsection*{Gradient with respect to \texorpdfstring{$C_0$}{C0}}

\begin{align*}
  \frac{\partial L}{\partial C_0}
  &= \frac{\partial}{\partial C_0} \left[ \frac{1}{n} \sum_{i=1}^{n} e_i^2 \right] \\
  &= \frac{1}{n} \sum_{i=1}^{n} 2 e_i \cdot \frac{\partial e_i}{\partial C_0} \\
  &= \frac{1}{n} \sum_{i=1}^{n} 2 e_i \cdot (-1) \qquad \left(\text{since } \frac{\partial e_i}{\partial C_0} = -1\right) \\[6pt]
  \Aboxed{
    \frac{\partial L}{\partial C_0} &= -\frac{2}{n} \sum_{i=1}^{n} \left( y_i - C_0 - C_1 x_i^2 \right)
  }
\end{align*}

\subsection*{Gradient with respect to \texorpdfstring{$C_1$}{C1}}

\begin{align*}
  \frac{\partial L}{\partial C_1}
  &= \frac{\partial}{\partial C_1} \left[ \frac{1}{n} \sum_{i=1}^{n} e_i^2 \right] \\
  &= \frac{1}{n} \sum_{i=1}^{n} 2 e_i \cdot \frac{\partial e_i}{\partial C_1} \\
  &= \frac{1}{n} \sum_{i=1}^{n} 2 e_i \cdot (-x_i^2) \qquad \left(\text{since } \frac{\partial e_i}{\partial C_1} = -x_i^2\right) \\[6pt]
  \Aboxed{
    \frac{\partial L}{\partial C_1} &= -\frac{2}{n} \sum_{i=1}^{n} \left( y_i - C_0 - C_1 x_i^2 \right) x_i^2
  }
\end{align*}

% ══════════════════════════════════════════════════════════════════════════════
\section{Task 3 — Update Rules}

At each iteration $t$, the parameters are updated by moving in the direction \textbf{opposite to the gradient}, scaled by the learning rate $\eta$:

\[
  \boxed{C_0^{(t+1)} = C_0^{(t)} - \eta \cdot \frac{\partial L}{\partial C_0}}
\]

\[
  \boxed{C_1^{(t+1)} = C_1^{(t)} - \eta \cdot \frac{\partial L}{\partial C_1}}
\]

Both parameters are updated \textbf{simultaneously} using gradients computed from the current values $C_0^{(t)}$ and $C_1^{(t)}$. The learning rate $\eta$ controls the size of each step:
\begin{itemize}
  \item Too large: may overshoot the minimum (oscillation/divergence)
  \item Too small: converges slowly, requiring many iterations
\end{itemize}

\subsection*{Algorithm (Batch Gradient Descent)}

At each iteration, using \textbf{all} $n = 100$ observations:

\begin{enumerate}
  \item Compute predicted values: $\hat{y}_i = C_0 + C_1 x_i^2$
  \item Compute residuals: $e_i = y_i - \hat{y}_i$
  \item Compute MSE loss: $L = \frac{1}{n}\sum_i e_i^2$
  \item Compute gradients: $\nabla_{C_0} = -\frac{2}{n}\sum_i e_i$, \quad $\nabla_{C_1} = -\frac{2}{n}\sum_i e_i x_i^2$
  \item Update: $C_0 \leftarrow C_0 - \eta\,\nabla_{C_0}$, \quad $C_1 \leftarrow C_1 - \eta\,\nabla_{C_1}$
\end{enumerate}
